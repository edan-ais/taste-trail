# Taste Trail
Pick a few favorites (artists, films, books, places), name a city, and get a one-day itinerary plus a soundtrack, a watch and a read, all driven by Qloo's Taste AI API (cross-domain taste signals).
Run: `QLOO_API_KEY=your_key node server.mjs` then open http://localhost:3000. Node 18+, no dependencies. The key stays server-side and is never committed.
